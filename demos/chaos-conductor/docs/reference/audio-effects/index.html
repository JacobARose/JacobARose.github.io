Audio effects

Play: knows synths and loopsDeep: exact behavior

In short: the Audio Effects panel is a chain of eleven effects. Sound goes through them from top to bottom. Switch each one on or off, change its settings, and map any setting to the XY pad.

Note

The parameter tables on this page are generated from the app’s code, so the ranges and defaults always match the version of the app the guide was built for.

Card controls

Section titled “Card controls”

Each effect is one card.

Control What it does
⠿ handle Drag to move the effect up or down the chain
Switch Turn the effect on or off
Title or ▸ Show or hide the effect’s parameters
Badges The parameters mapped to the pad, such as Y: FREQUENCY
▲ ▼ arrows Move the card one place up or down the chain (left or right when the cards run sideways)

Each parameter row has:

Control What it does
Knob or slider Set the value. Drag knobs up or down, and sliders along their track
↺ Reset to the default value
X Map to the X axis (toggle)
⇄ next to X Invert the X mapping. Shown once the parameter is mapped
Y Map to the Y axis (toggle)
⇄ next to Y Invert the Y mapping. Shown once the parameter is mapped

While you play, mapped parameters show the values the pad is setting.

Input Mixer

Section titled “Input Mixer”

Always at the top of the chain, and collapsible.

Knob Range Default What it does
SYNTH 0% (dry) to 100% (wet) 100% How much of the synth goes through the effects. The rest skips them
DRUMS 0% (dry) to 100% (wet) 100% The same, for the drums

The effects

Section titled “The effects”

These are listed in their order in a new session. Only Filter starts switched on.

Filter

Section titled “Filter”

A low-pass filter: it removes high frequencies above the cutoff, making the sound darker. Resonance boosts the frequencies right at the cutoff for a sharper, more vocal sweep. At 20,000 Hz it’s fully open and has no effect.

ParameterRangeDefaultSweepMapped by default
Frequency20 Hz to 20,000 Hz20,000 HzLogarithmicY
Resonance0.7 to 201Linearnone

Filter is on in a new session. Any parameter can be mapped to X or Y; the last column is only the starting mapping.

Distortion

Section titled “Distortion”

Overdrives the sound for grit and crunch. Mix blends the distorted sound with the clean one.

Reverb

Section titled “Reverb”

Adds the sound of a room. Decay is how long the tail lasts, Pre-delay is the gap before the reverb starts, and Damping is how much the tail darkens as it fades.

ParameterRangeDefaultSweepMapped by default
Mix0 to 10.5Linearnone
Decay100 ms to 10 s2 sLinearY
Pre-Delay0 s to 100 ms20 msLinearnone
Damping100 Hz to 20,000 Hz5,000 HzLogarithmicnone

Reverb is off in a new session. Any parameter can be mapped to X or Y; the last column is only the starting mapping.

Delay

Section titled “Delay”

Echoes. Time is the gap between echoes, Feedback is how many repeats there are, and the cutoff darkens each repeat.

ParameterRangeDefaultSweepMapped by default
Time10 ms to 2 s500 msLinearnone
Feedback0 to 0.950.4Linearnone
Mix0 to 10.5Linearnone
Cutoff100 Hz to 20,000 Hz2,000 HzLogarithmicnone

Delay is off in a new session. Any parameter can be mapped to X or Y; the last column is only the starting mapping.

The SYNC MODE buttons on the card choose how Time works:

  • BEAT SYNC (default): Time steps through note values that follow the BPM:

    1/64, 1/32, 1/16, 1/8, 1/4, 1/2, 1 Bar, 2 Bars

  • TIME: Time is free, in seconds.

Bit Crusher

Section titled “Bit Crusher”

Lo-fi degradation. Bit depth lowers the resolution (fewer bits is harsher), and Reduction lowers the sample rate for an aliased, digital sound.
